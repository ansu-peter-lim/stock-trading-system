Stock Trading Strategy V1 요구사항 명세
1. 목적

본 전략은 일봉으로 종목의 추세와 Core 매수·매도 여부를 판단하고, 5분봉으로 실제 매수·매도 실행 시점을 결정한다.

추가로 보유 중인 종목은 5분봉 추세를 이용해 최대 배정금액의 10%를 Tactical 물량으로 부분 매매한다.

핵심 원칙은 다음과 같다.

일봉 = 방향 / 매매 자격 / Core 포지션 판단
5분봉 = 실제 실행 타이밍 / Tactical 10% 조절

모든 판단은 완성된 봉만 사용하며 미래 데이터를 사용하지 않는다.

2. 공통 원칙
2.1 일봉 판단

모든 일봉 판단은 당일 종가 확정 이후 수행한다.

T일 종가로 발생한 매수·매도 신호는 T일 거래에 사용할 수 없다.

T일 종가
→ 일봉 신호 확정
→ T+1 거래일부터 5분봉으로 실행 판단
2.2 5분봉 판단

5분봉 역시 해당 봉의 종가가 확정된 이후에만 신호를 판단한다.

백테스트 V1의 체결가격은:

5분봉 신호 확정
→ 다음 5분봉 시가 체결

로 한다.

2.3 5분 이동평균

5분 MA는 매일 장 시작 때 초기화하지 않는다.

전 거래일에서 이어지는 연속된 5분봉 시계열로 계산한다.

3. 사용 이동평균
일봉
MA10
MA20
MA60
5분봉
MA10
MA20
MA60

모두 단순이동평균(SMA)을 V1 기본값으로 한다.

4. 일봉 추세 판정

MA20과 MA60의 최근 5거래일 변화 방향으로 판단한다.

MA20_slope = MA20_today / MA20_5days_ago - 1
MA60_slope = MA60_today / MA60_5days_ago - 1
상승추세
MA20_slope > 0
AND
MA60_slope > 0
하락추세
MA20_slope < 0
AND
MA60_slope < 0
박스권

두 기울기의 방향이 반대다.

MA20_slope > 0 AND MA60_slope < 0

OR

MA20_slope < 0 AND MA60_slope > 0

정확히 0인 경우는 V1에서 NEUTRAL로 분류하고 신규 진입을 하지 않는다.

5거래일은 V1 기본값이며 향후 3/5/10일 비교가 가능하도록 파라미터화한다.

5. 하락추세 전략
5.1 기본 반전 조건

최근 10거래일 이상 종가가 MA10 아래에서 유지된 종목을 대상으로 한다.

이후:

당일 Close > MA10

이 되면 MA10 돌파로 판단한다.

5.2 상승률 5~10%

당일 상승률이:

5% <= 상승률 <= 10%

이고 종가가 MA10을 돌파했으며 매수금지 필터가 없다면 일봉 매수 후보가 된다.

실제 매수는 익일 5분봉 조건에 따른다.

6. 하락추세 매수금지 필터
6.1 MA20 급하락

차트상의 각도는 사용하지 않는다.

V1에서는:

MA20_slope_5d <= -5%

이면 급하락으로 판단하고 신규매수를 금지한다.

향후 후보:

-3% / -5% / -7%
6.2 MA20/MA60 저항

당일 고가가 MA20 또는 MA60의 ±3% 영역에 접근했으나 종가가 해당 이동평균 아래라면 저항을 받은 것으로 판단한다.

High가 MA20 또는 MA60 ±3% 접근
AND
Close < 해당 MA

→ 신규매수 금지

향후 2/3/5%를 비교할 수 있도록 파라미터화한다.

7. 하락추세 — 5% 미만 상승

MA10 돌파가 발생했더라도 당일 상승률이 5% 미만이면 일반적인 단일봉 반전매수는 하지 않는다.

단, 적삼병 조건을 만족하면 매수 후보로 인정한다.

V1 적삼병:

최근 3거래일 모두:

Close > Open

AND

Close[t] > Close[t-1] > Close[t-2]

MA20 급하락 및 MA20/MA60 저항 필터는 동일하게 적용한다.

8. 하락추세 — 10% 초과 상승

당일 상승률이 10%를 초과하면 강한 반전으로 보지만 즉시 추격매수하지 않는다.

상승률 > 10%
→ 즉시 매수 금지
→ MA10 눌림 대기

이후 당일 Low 또는 Close가:

MA10 × 0.97 ~ MA10 × 1.03

범위에 도달하면 다시 매수 후보 자격을 부여한다.

그 후 실제 매수는 5분봉 진입 규칙을 적용한다.

9. 하락추세 매도

반전매수 이후:

일봉 Close < MA10

이면 전량매도 판정을 발생시킨다.

실제 매도는 익일 5분봉 매도 실행 규칙을 적용한다.

10. 박스권 조건

박스권은 우선 추세 조건을 만족해야 한다.

MA20 / MA60 기울기 방향 반대

그리고 박스폭이 최소 25% 이상이어야 한다.

박스폭 =
(전고점 - 전저점) / 전저점

박스폭 >= 25%
11. 전고점 / 전저점

V1에서는 확정된 5-bar Pivot을 사용한다.

Pivot Low는 중앙 봉의 저가가 좌측 2봉과 우측 2봉의 저가보다 낮은 경우다.

Pivot High는 반대다.

중요한 look-ahead 방지 원칙:

t일 Pivot 후보
→ t+1
→ t+2
→ t+2 봉이 완성된 이후
→ Pivot 확정

따라서 Pivot 발생일 당시에는 해당 Pivot을 사용할 수 없다.

12. 박스권 매수

전저점 부근은:

Pivot Low × 0.95
<= 당일 Low <=
Pivot Low × 1.05

로 정의한다.

전저점 부근에 도달한 상태에서 당일 상승률이:

5% 이상 ~ 10% 이하

이면 일봉 매수 후보가 된다.

실제 진입은 익일 5분봉 매수 실행 규칙을 따른다.

13. 박스권 손절

일봉 종가가:

Close < 전저점

이면 전량매도 판정을 발생시킨다.

실제 매도는 익일 5분봉 매도 실행 규칙을 적용한다.

14. 박스권 익절

당일 고가가:

Pivot High × 0.95
<= High <=
Pivot High × 1.05

에 도달하면 전고점 부근으로 판단한다.

V1에서는 100% 익절 판정을 발생시킨다.

실제 매도는 익일 5분봉 매도 실행 규칙을 적용한다.

15. 상승추세 전략

상승추세:

MA20 상승
AND
MA60 상승

상승추세에서는 MA20 눌림을 Core 매수의 핵심으로 한다.

V1의 MA20 부근:

MA20 × 0.97
~
MA20 × 1.03

해당 영역에 도달하면 매수 후보가 된다.

FULL은 전체 계좌금액이 아니라:

해당 종목에 배정할 수 있는 최대 목표금액의 100%

를 의미한다.

16. 상승추세 MA10 이상

주가가 MA10 이상에 있다면 일봉만 보고 FULL 추격매수하지 않는다.

보유 상태에서는 5분봉 Tactical 매매를 활용한다.

17. 상승추세 전량매도

일봉:

Close < MA20

이면 전량매도 판정을 발생시킨다.

실제 매도는 익일 5분봉 매도 실행 규칙에 따른다.

18. 일봉 매수판정 → 5분봉 실제 매수

일봉 매수판정이 발생하면 익일 장 시작 즉시 매수하지 않는다.

첫 번째 5분봉이 완전히 확정될 때까지 기다린다.

첫 확정봉에서:

MA20 > MA60

이면 이미 단기 상승추세가 유지되고 있다고 판단한다.

일봉 매수판정
→ 익일 첫 5분봉 확정
→ MA20 > MA60
→ 매수신호
→ 다음 5분봉 시가 매수

첫 확정봉에서:

MA20 <= MA60

이면 매수하지 않고 대기한다.

이후 장중 새로운 Golden Cross:

이전 봉 MA20 <= MA60
AND
현재 봉 MA20 > MA60

가 발생하면 매수한다.

따라서 Core 진입 조건은:

익일 첫 확정봉 MA20 > MA60

OR

이후 새로운 MA20/MA60 Golden Cross

이다.

19. 일봉 매도판정 → 5분봉 실제 매도

일봉에서 전량매도 판정이 발생하더라도 익일 시초에 즉시 매도하지 않는다.

목적은 장 초반 반발매수 흐름을 너무 일찍 매도하지 않고 이용하기 위해서다.

익일 장중 최초로:

5분봉 Close < MA60

가 확정되는 시점을 단기 추세가 꺾인 것으로 판단한다.

일봉 매도판정
        ↓
익일 반발 허용
        ↓
Close >= MA60
→ 계속 보유

Close < MA60
→ 전량매도 신호
→ 다음 5분봉 시가 전량매도

장 시작부터 약하면 첫 확정 5분봉에서 조건이 만족되어 빠르게 매도된다.

V1에서는 하락/박스/상승 전략 모두 동일한 실행 원칙을 적용한다.

20. Tactical 부분매매 기본 구조

Tactical 매매는 이미 보유하고 있는 종목의 단기 비중 조절이다.

1 Tactical Unit:

해당 종목 FULL 배정금액 × 10%

현재 보유금액의 10%가 아니다.

예:

종목 최대 배정금액 = 1,000만원

1 Unit = 100만원

V1에서는 Tactical이 Core 전략을 대체하지 않는다.

21. Tactical 부분매수

새로운 5분봉 MA20/MA60 Golden Cross가 발생해야 한다.

이전 봉:
MA20 <= MA60

현재 봉:
MA20 > MA60

발생 시:

+1 Tactical Unit

매수한다.

단, 전체 포지션은 FULL을 초과할 수 없다.

중요한 구분

Core 최초 진입은:

첫 5분봉 MA20 > MA60

만으로 가능하다.

그러나 Tactical 추가매수는 반드시 새로운 GC 이벤트가 실제 발생해야 한다.

단순히 MA20 > MA60 상태가 유지된다는 이유로 반복매수하지 않는다.

22. Tactical 부분매도

새로운 5분봉 MA10/MA20 Dead Cross:

이전 봉:
MA10 >= MA20

현재 봉:
MA10 < MA20

발생 시:

-1 Tactical Unit

을 매도한다.

단, 한 번 Tactical 매도를 실행한 뒤에는 다시 Tactical 1 Unit을 매수하기 전까지 추가 Tactical 매도를 금지한다.

상태는 다음과 같다.

READY
  │
  │ MA10/20 DC
  ▼
-1 Unit 매도
  │
  ▼
SELL_LOCK
  │
  ├─ DC → 무시
  ├─ DC → 무시
  ├─ DC → 무시
  │
  │ MA20/60 GC
  ▼
+1 Unit 매수
  │
  ▼
READY

따라서 Tactical 거래는 기본적으로:

-10% → +10% → -10% → +10%

형태의 왕복 조절이다.

한 하락 파동에서 DC가 반복된다는 이유로 Core 물량을 계속 줄이지 않는다.

23. Tactical 상태 초기화

새로운 Core 포지션을 구축하면:

tactical_sell_lock = False

로 초기화한다.

전량청산 후에도 Tactical 상태를 초기화한다.

24. 일봉 전량매도와 Tactical의 우선순위

일봉 전량매도 판정은 Tactical SELL_LOCK보다 우선한다.

예:

FULL 100%

5분 DC
→ 10% 매도
→ 보유 90%
→ SELL_LOCK

이후 일봉 전량매도 판정

→ SELL_LOCK 무시
→ 익일 Close < MA60 확인
→ 나머지 90% 전량청산

또한 일봉 전량매도 판정이 활성화된 상태에서는 새로운 Tactical 매수를 금지한다.

25. 신호 처리 우선순위

동일 시점에 여러 조건이 발생하면:

1. 기존 일봉 전량매도 상태 확인
2. 신규매수 금지 필터
3. 일봉 추세 판정
4. 추세별 일봉 매수/매도 판정
5. Core 목표 포지션 결정
6. 익일 5분봉 Core 실행
7. 보유종목 Tactical 매매

일봉 전량매도 대기 상태에서는 5분 GC가 발생해도 Tactical 추가매수를 하지 않는다.

27. 백테스트에서 반드시 비교할 항목

V1 자체를 먼저 고정하여 기준 결과를 만든다.

그 다음 한 번에 여러 조건을 바꾸지 않고 한 변수씩 비교한다.

특히 Core 매도는 친구의 시장 관찰을 검증하기 위해 다음을 별도로 비교한다.

A. 일봉 매도판정 → 익일 시가 매도

B. 일봉 매도판정 → 익일 첫 5분봉 후 매도

C. 일봉 매도판정
   → 익일 반발 허용
   → 최초 Close < 5분 MA60
   → 다음 봉 매도

V1 실전 가설은 C다.

평가는 단순 총수익률뿐 아니라 최소한:

CAGR / 누적수익률
MDD
승률
평균 수익 / 평균 손실
Profit Factor
거래 횟수
평균 보유기간
Turnover
슬리피지/비용 반영 수익

을 같이 본다.

특히 매도 방식 A/B/C에서는 일봉 매도판정 이후 실제 청산까지의 추가 수익/손실을 별도 기록한다.

28. V1에서 의도적으로 하지 않는 것

처음부터 최적의 숫자를 찾으려고 하지 않는다.

±3%, ±5%, 10일, 25%, -5% 등은 전략의 진실이라고 가정하는 값이 아니라 V1 기준값이다.

먼저:

V1 고정
 ↓
백테스트
 ↓
실패/성공 패턴 분석
 ↓
하나의 조건 변경
 ↓
재백테스트

순서로 개선한다.

또한 V1에서는 AI/ML을 이용해 추세를 분류하지 않는다.

29. 구현 원칙

이건 Codex에게 특히 중요하게 전달해야 해.

전략 로직과 백테스트 엔진을 분리한다.

개념적으로:

Daily Data
   ↓
Daily State Classifier
   ↓
Daily Signal Generator
   ↓
Pending Core Action
   ↓
5-Min Execution Engine
   ↓
Position Manager
   ├─ Core
   └─ Tactical State
   ↓
Trade Ledger
   ↓
Performance Analysis

그래야 나중에 MA20 급하락 -5% → -3%처럼 전략을 수정해도 체결 엔진 전체를 뜯어고치지 않아도 돼.

그리고 모든 신호에는 최소한:

signal_generated_at
signal_available_at
execution_signal_at
executed_at
reason
strategy_state

를 남기는 걸 추천해.
